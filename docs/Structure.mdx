# Structure

## Library layout

```
./
├── components/       # 98 reusable React components
├── hooks/            # Custom React hooks
├── providers/        # Context providers (theme, translation, error boundary)
├── context/          # React context definitions
├── errors/           # Error page components
├── constants/        # Shared constants
├── enums/            # TypeScript enums
├── types/            # TypeScript type definitions
├── utils/            # Utility functions
├── styles/           # Global SCSS, mixins, variables
├── locales/          # i18n translation files (English is committed)
└── assets/           # Static assets (images, icons)
```

These ship in the package too, but are coupled to a DocSpace portal rather than being
general-purpose UI — see `docs/public-api.md` for the tiering:

```
./
├── ai-agent/         # AI chat panel and settings
├── api/              # Portal REST client
├── billing/          # Tariff, payment and services flows
├── document-editor/  # Document editor wrapper
├── selectors/        # Data-driven selectors (room, files, people, groups, ...)
└── uploader/         # Upload UI
```

## Tech stack

- **React 19** — UI framework (a peer dependency, along with React-DOM)
- **TypeScript 5.9** — type safety
- **SCSS Modules + CSS custom properties** — component styling; no runtime CSS-in-JS
- **Rollup** — library build, ESM only
- **MobX 6** — state management, in the portal-coupled stores
- **i18next** — internationalization
- **Biome** — linting only; its formatter is disabled and Prettier formats
- **Vitest** — unit testing
- **Storybook** — component documentation
