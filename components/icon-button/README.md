# IconButton

Icon that acts as a button, with hover and pressed colours and an optional tooltip. It is the
control for a row action or a toolbar, where a label would not fit.

## Use this when / not when

- Use for an action that a recognisable icon explains on its own: close, copy, more, refresh.
- Not for an action with a label — [`Button`](../button/README.md) is a real button element,
  focusable and named, and it takes an icon too.
- Not for an icon that opens a menu of actions: that is
  [`ContextMenuButton`](../context-menu-button/README.md).
- Not for a decorative icon. This one keeps its hover colours whether or not anything
  happens, and shows a pointer cursor as soon as it has an `onClick` or `isClickable`.

## Import

```ts
import { IconButton } from "@onlyoffice/apps-ui-kit/components/icon-button";
```

Also exported from the root barrel `@onlyoffice/apps-ui-kit`.

Needs `ThemeProvider` from `@onlyoffice/apps-ui-kit/providers/theme` above it in the tree for
the icon's default colour and for `color="accent"`.

## Minimal example

Pass the icon as a node. It needs no network request and your bundler types it. With an
`onClick` the button is focusable, has `role="button"`, answers Enter and Space, and is named by
`title`.

```tsx
import { IconButton } from "@onlyoffice/apps-ui-kit/components/icon-button";

export function CloseButton({ onClose }: { onClose: () => void }) {
  return (
    <IconButton
      size={16}
      title="Close"
      onClick={onClose}
      iconNode={
        <svg viewBox="0 0 16 16" aria-hidden="true">
          <path
            d="M4 4l8 8M12 4l-8 8"
            stroke="currentColor"
            strokeWidth="1.5"
          />
        </svg>
      }
    />
  );
}
```

## Recipes

### Disable the button while an action runs

```tsx
import { IconButton } from "@onlyoffice/apps-ui-kit/components/icon-button";

export function RefreshButton({
  busy,
  onRefresh,
}: {
  busy: boolean;
  onRefresh: () => void;
}) {
  return (
    <IconButton
      size={16}
      isDisabled={busy}
      title="Refresh"
      onClick={onRefresh}
      iconNode={
        <svg viewBox="0 0 16 16" aria-hidden="true">
          <circle
            cx="8"
            cy="8"
            r="6"
            fill="none"
            stroke="currentColor"
            strokeWidth="1.5"
          />
        </svg>
      }
    />
  );
}
```

### Load the icon from a URL

`iconName` is a URL that the browser fetches, so it has to be one your bundler produced or one
under your public directory.

```tsx
import { IconButton } from "@onlyoffice/apps-ui-kit/components/icon-button";
import trashUrl from "./trash.svg?url";

export function DeleteButton({ onDelete }: { onDelete: () => void }) {
  return (
    <IconButton
      size={16}
      iconName={trashUrl}
      color="--accent-main"
      title="Delete"
      onClick={onDelete}
    />
  );
}
```

## Behaviour the types don't state

- **`iconName` is a URL.** `react-svg` fetches it and inlines the markup. An asset name, an SVG
  imported as a component, or a build-time alias of the ONLYOFFICE Apps client will not work.
  `iconNode` needs no request at all.
- **It renders a `<div>`, not a `<button>`.** With an `onClick` and no `isDisabled`, it adds the
  button semantics itself: `tabIndex={0}`, `role="button"`, `title` as the `aria-label`, and
  Enter and Space calling `onClick`.
- **A key press arrives as a click at the button's lower start corner**, so a menu opened at
  `pageX` / `pageY` lands next to the button. The key press is kept from the page-wide hotkeys.
- **Passing `tabIndex` or `onKeyDown` switches the built-in keyboard support off.** The keyboard
  is then yours. `role` and `ariaLabel` override their defaults one by one.
- The keyboard focus gets a 2px accent ring (`--icon-button-focus-color`); the pointer gets none.
- **`onMouseUp` fires only for the middle and right buttons.** The component treats button `1`
  as the left one, but the left button is `0`. Use `onClick`.
- The hover and pressed icon swaps are suppressed on a touch device, detected by `ontouchstart`.
- **`isDisabled` blocks every handler, including the colour swaps, and sets `aria-disabled`.** The
  element stays in the tab order if you gave it one.
- **A disabled button looks the same as an enabled one.** Only the cursor changes, to the arrow;
  the icon keeps its default colour.
- The cursor is the pointer only when the button has an `onClick` or `isClickable`; otherwise
  it is the arrow.
- With `tooltipId` and `tooltipContent` the button renders its own `Tooltip` below itself,
  which follows the pointer on a desktop and stays put elsewhere.
- `title` feeds the shared tooltip and reaches the DOM as a native attribute only under
  `NODE_ENV=test`.

## CSS variables

The first three are written into the button's inline style from `size` and `color`, so a value
set on a wrapper never arrives. Change them through those props, or on the button's own `style`
prop, which is applied after them. `color` also takes a custom property name
(`color="--accent-main"`) and wraps it in `var()`. The two focus variables are read with a
fallback, so they can be set on an ancestor too.

| Variable                     | Default             | Effect                                                                    |
| ---------------------------- | ------------------- | ------------------------------------------------------------------------- |
| `--icon-button-color`        | theme               | Icon colour: the fill, or the outline under `isStroke`                    |
| `--icon-button-hover-color`  | theme               | Icon colour under a mouse pointer; once `color` is set, `hoverColor` wins |
| `--icon-button-size`         | `20px`, from `size` | Width and height of the button                                            |
| `--icon-button-focus-color`  | `--accent-main`     | Colour of the keyboard focus ring                                         |
| `--icon-button-focus-offset` | `2px`               | Gap between the ring and the button; negative draws it inside             |

A negative `--icon-button-focus-offset` keeps the ring visible in a container that clips its
overflow flush with the button.

## Accessibility

- With an `onClick` the element is a focusable `role="button"` named by `ariaLabel`, or by
  `title` when that is unset; give it one of the two. Without an `onClick` it has no role and
  no tab stop — right for an icon whose click an ancestor handles (`isClickable`).
- `aria-disabled` is always set: `true` while `isDisabled`, `false` otherwise.
- `ariaLabel` becomes the element's `aria-label`. A raw `aria-*` attribute is applied last, so
  it is kept and wins over the component's own `aria-label` and `aria-disabled`.
- For an icon-only action that has to be usable by everyone, `Button` with `aria-label` is the
  safer component.
