# AppLoader

The blank first screen: a fixed sheet over the whole viewport with the kit's rombs animation on it.
Its one prop is the text a screen reader announces — render it while the application boots and
stop rendering it when it is ready.

## Use this when / not when

- Use for the very first paint, before there is a layout to put a smaller loader into.
- **It covers the viewport, wherever it is rendered.** The sheet is `position: fixed` at
  `z-index: 5000`, so putting it inside a panel does not confine it to that panel.
- Not for a section or a panel that is refreshing — wrap that in
  [`LoaderWrapper`](../loader-wrapper/README.md) or show a [`Loader`](../loader/README.md) in place.
- Not for a navigation that is only slow — the thin bar at the top of the page is
  [`TopLoaderService`](../top-loading-indicator/README.md).
- **It is opaque.** The page behind it is hidden, not dimmed; there is no backdrop and nothing
  shows through.

## Import

```ts
import AppLoader from "@onlyoffice/apps-ui-kit/components/app-loader";
```

It is a **default** export, so the name is yours to choose. The root barrel carries it by name as
well, as `AppLoader`.

Prefer the subpath: the barrel does not build without four optional peers. See
[Which import form](../../docs/getting-started.md#which-import-form).

No provider is required: the sheet is white and the animation dark by default. The dark theme's
grey sheet comes from the provider's `dark` class, so without a provider it stays light.

## Minimal example

```tsx
import { useEffect, useState } from "react";

import AppLoader from "@onlyoffice/apps-ui-kit/components/app-loader";
import { Text } from "@onlyoffice/apps-ui-kit/components/text";

export function App() {
  const [ready, setReady] = useState(false);

  useEffect(() => {
    const id = setTimeout(() => setReady(true), 1200);
    return () => clearTimeout(id);
  }, []);

  if (!ready) return <AppLoader />;

  return <Text>Ready</Text>;
}
```

## Recipes

### Keeping it above, or below, your own layers

The sheet's stacking order is a custom property. Lower it when something of yours — a debug bar, a
cookie notice — has to stay visible over the boot screen.

```tsx
import type { CSSProperties } from "react";

import AppLoader from "@onlyoffice/apps-ui-kit/components/app-loader";

export function BootScreen() {
  return (
    <div style={{ "--app-loader-z-index": "100" } as CSSProperties}>
      <AppLoader />
    </div>
  );
}
```

### Your own background

`--app-loader-bg` wins over both theme colours, so a branded splash needs one declaration and no
class.

```tsx
import type { CSSProperties } from "react";

import AppLoader from "@onlyoffice/apps-ui-kit/components/app-loader";

export function BrandedBoot() {
  return (
    <div style={{ "--app-loader-bg": "#0f4071" } as CSSProperties}>
      <AppLoader />
    </div>
  );
}
```

## Behaviour the types don't state

- **Its only prop is `label`.** There is no size, colour or delay; everything visual that is
  adjustable is a custom property, and the two below are all of them.
- **`width: 100vw` is wider than the page when a scrollbar is showing.** On a scrolled document
  the sheet can add a horizontal scrollbar of its own.
- **The animation is not centred by the flex box.** The child is itself `position: fixed` at
  `top: 35%` and `inset-inline-start: calc(50% - 20px)`.
- That is a third of the way down the viewport, and half a spinner left of the middle.
- **It traps nothing.** Focus, scrolling and keyboard shortcuts on the page underneath all still
  work; the sheet only paints over them.
- **It is not a portal.** It renders where you put it. Under an ancestor with a `transform`, a
  `filter` or `contain`, the fixed positioning resolves against that ancestor, and the sheet stops
  covering the page.
- The animation is the kit's `rombs` type at 40px, hard-coded. Nothing switches it off for
  `prefers-reduced-motion`.

## CSS variables

| Variable               | Default                                      | Effect                      |
| ---------------------- | -------------------------------------------- | --------------------------- |
| `--app-loader-bg`      | `#ffffff`, or `#333333` under the dark theme | Background of the sheet     |
| `--app-loader-z-index` | `5000`                                       | Stacking order of the sheet |

Set them on any ancestor.

## Accessibility

- **The wait is announced.** The animation is a [`Loader`](../loader/README.md), a
  `role="status"` region with `label` as its hidden text. Without one it reads the translated
  `Common:LoadingProcessing` ("Loading...").
- The diamonds are `aria-hidden`, and the sheet carries `aria-busy="true"`.
- **A passed `aria-*` lands on the status region and is kept.** An `aria-label` names the region.
- Focus is not moved or trapped. A keyboard user can tab into the page hidden behind the sheet
  and use controls they cannot see.
- The animation runs for as long as the component is mounted, whatever the viewer's motion
  preference.
