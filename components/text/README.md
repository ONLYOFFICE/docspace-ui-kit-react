# Text

Body text at the kit's size and weight, rendered through whichever element you name. It is the
typography primitive the kit builds its labels from: a `<p>` by default, 13px and 400, styled
through props instead of a class.

## Use this when / not when

- Use for a line or a paragraph in the kit's type, or for text that must truncate, stay
  unselectable or follow its own direction.
- Use when a component of yours wants the kit's default body size without hard-coding 13px.
- Not for a section title — use [`Heading`](../heading/README.md), which carries the sizes, the
  weight and the theme's text colour, and renders a real `h1`–`h6`.
- Not for a form field's label — use [`Label`](../label/README.md), which ties itself to the
  control and draws the required asterisk.
- Not for something clickable — use [`Link`](../link/README.md). `Text` takes an `onClick`, but
  without a role, focus or key handling the click is unreachable from the keyboard.

**It paints no colour of its own.** Unlike every other text component in the kit, `Text` sets
neither `color` nor `font-family`; both are inherited from whatever contains it. On a page that
never set them you get the browser's defaults, in the light theme and the dark one alike. Pass
`color`, or set `color` on a container.

## Import

```ts
import { Text } from "@onlyoffice/apps-ui-kit/components/text";
```

Also exported from the root barrel `@onlyoffice/apps-ui-kit`.

No provider is required: the component reads only `--text-size` and `--text-weight`, both with
built-in fallbacks, so it renders correctly on its own.

## Minimal example

```tsx
import { Text } from "@onlyoffice/apps-ui-kit/components/text";

export function FileMeta() {
  return (
    <div>
      <Text isBold>Quarterly report.docx</Text>
      <Text color="#a3a9ae">Modified 12 minutes ago</Text>
    </div>
  );
}
```

## Recipes

### Truncate a long name in a flex row

`truncate` is one line plus an ellipsis, and it only bites inside a parent of bounded width. In a
flex row the item needs `min-width: 0` as well. Without it a flex child refuses to shrink below
its content, and the text overflows instead of clipping.

```tsx
import { Text } from "@onlyoffice/apps-ui-kit/components/text";

export function FileRow({ name, size }: { name: string; size: string }) {
  return (
    <div style={{ display: "flex", gap: 8, width: 240 }}>
      <div style={{ minWidth: 0, flex: 1 }}>
        <Text truncate>{name}</Text>
      </div>
      <Text color="#a3a9ae">{size}</Text>
    </div>
  );
}
```

### Show a user-supplied name in its own direction

`dir="auto"` does not set the attribute on the element. It wraps the children in an inner span
with `dir="auto"`, so the browser picks the direction from the content's first strong character.
That suits a file name in a mixed-script portal.

```tsx
import { Text } from "@onlyoffice/apps-ui-kit/components/text";

export function FileName({ name }: { name: string }) {
  return (
    <Text dir="auto" truncate>
      {name}
    </Text>
  );
}
```

### Render text as a list item or another element

`as` takes the element, and the text keeps its styling. This is how you get semantic markup
without giving up the kit's typography.

```tsx
import { Text } from "@onlyoffice/apps-ui-kit/components/text";

export function Legend() {
  return (
    <ul>
      <Text as="li">Owners can invite members</Text>
      <Text as="li">Members can upload files</Text>
    </ul>
  );
}
```

## Behaviour the types don't state

- **The element is a `<p>` unless you say otherwise.** `as` wins over `tag` when both are set.
- A `<p>` cannot contain a `<div>`: the browser's parser closes the paragraph, and the block child
  ends up as a sibling. Pass `as="div"` or `as="span"` when the children are not phrasing content.
- **`style` is merged last**, over `fontSize`, `fontWeight`, `color`, `textAlign`, `lineHeight` and
  `backgroundColor`. A `style={{ fontSize: "16px" }}` beats `fontSize="13px"`, not the other way
  round.
- **`isBold` overrides `fontWeight`** rather than combining with it: the inline weight becomes 700
  and the `bold` class sets the same, so `isBold fontWeight={500}` renders at 700.
- **`containerWidth` and `containerMinWidth` do nothing here, and are not dead.**
  [`RowContent`](../rows/row-content/README.md) and [`TileContent`](../tiles/tile-content/README.md)
  read them off the child they are given, as the width of the slot they put it in.
- Set them only inside one of those two wrappers.
- **`title` is a tooltip, not a `title` attribute.** The folder exports `withTooltip(TextUi)`, and
  the wrapper consumes `title` before the element is built.
- The tooltip opens on hover after 700ms, and only once `<RootTooltip />` from
  [`Tooltip`](../tooltip/README.md) is mounted near the root of the app.
- Under `NODE_ENV === "test"` the wrapper passes `title` through as the attribute, so a test sees
  what a browser does not.
- **`TextUi` is the same component without that wrapper**, exported for the cases where you want
  a real `title` attribute or no hover handlers at all.
- **`truncate` clips, it does not wrap to a line count.** The only multi-line clamp is
  `view="tile"`: two lines, and only together with `dir="auto"`, since it styles that mode's span.
- **The auto-direction span takes the pointer events off the text** (`pointer-events: none`). With
  `dir="auto"` the children get no hover or click of their own; put the handler on the `Text`.
- **`noSelect` covers the whole element**, including any children you pass. It is
  `user-select: none` in every engine the kit supports.

## CSS variables

All are read with a fallback, so setting one on any ancestor changes every `Text` below it.

| Variable             | Default         | Effect                                                                       |
| -------------------- | --------------- | ---------------------------------------------------------------------------- |
| `--text-size`        | `13px`          | Font size, unless the `fontSize` prop or `style` overrides it                |
| `--text-weight`      | `400`           | Font weight, unless `fontWeight`, `style` or `isBold` does                   |
| `--text-focus-color` | `--accent-main` | Keyboard focus ring of a focusable `Text` (a `Link`, or one with `tabIndex`) |

There is no variable for the colour: `Text` does not declare one and inherits instead.

## Accessibility

- The element is a `<p>` with no role and no ARIA of its own. `as` gives it structural meaning:
  `as="li"` in a list, `as="label"` with `htmlFor`, `as="span"` inside a sentence.
- **Every `aria-*` and `role` passed is kept**, spread onto the element. A line that reports an
  outcome is `role="status"` or `role="alert"` without a wrapper element.
- An `onClick` does not make it operable: there is no `tabIndex`, no `role="button"` and no key
  handler. Pass `tabIndex` and `role="button"` yourself, or use [`Link`](../link/README.md) or a
  button.
- `title` produces the kit's own tooltip rather than the native one, and the kit's tooltip is not
  announced by a screen reader. Text that must be read aloud belongs in the content or in an
  `aria-label` on the element.
- `dir="auto"` is the accessible way to render names in an unknown script; `dir="rtl"` forces the
  direction whatever the content is.
