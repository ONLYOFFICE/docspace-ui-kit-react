# TableGroupMenu

Toolbar that takes a section header's place while items are selected, with a select-all checkbox
and the actions for the selection. It was part of `Table` and outlived it: it belongs to the
header of the page, not to the list, so it works the same over a [`DataTable`](../data-table/README.md),
rows or tiles.

## Use this when / not when

- Use above a list whose items can be selected, in place of the list's title while the selection
  is not empty.
- Not for the actions of one item — that is the item's own menu, a
  [`ContextMenu`](../context-menu/README.md).
- It does not track the selection: what is ticked, and what "select all" selects, is the
  consumer's state, given as `isChecked` / `isIndeterminate` and changed through `onChange`.

## Import

```ts
import { TableGroupMenu } from "@onlyoffice/apps-ui-kit/components/table-group-menu";
```

Also exported from the root barrel `@onlyoffice/apps-ui-kit`, with `TGroupMenuItem` and
`TableGroupMenuProps`.

Needs `ThemeProvider` from `@onlyoffice/apps-ui-kit/providers/theme`, and `TranslationProvider`
from `@onlyoffice/apps-ui-kit/providers/translation`: the select-all checkbox's and the selection
combo box's titles are its own translations, and come back empty without it.

## Minimal example

```tsx
import { useState } from "react";
import { TableGroupMenu } from "@onlyoffice/apps-ui-kit/components/table-group-menu";

const NAMES = ["Report.docx", "Budget.xlsx", "Slides.pptx"];

export function SelectionBar() {
  const [selected, setSelected] = useState<string[]>(["Report.docx"]);

  if (!selected.length) return null;

  return (
    <TableGroupMenu
      isChecked={selected.length === NAMES.length}
      isIndeterminate={selected.length < NAMES.length}
      onChange={(checked) => setSelected(checked ? NAMES : [])}
      withoutInfoPanelToggler
      withComboBox={false}
      headerMenu={[
        {
          id: "delete",
          label: "Delete",
          title: "Delete the selected files",
          iconUrl: "",
          disabled: false,
          onClick: () => setSelected([]),
        },
      ]}
    />
  );
}
```

## Recipes

### Disabled

`isBlocked` greys every button out and ignores their clicks, for while an operation on the
selection runs. A single action that does not apply is left out instead: an entry whose
`disabled` is true renders nothing.

```tsx
import { TableGroupMenu } from "@onlyoffice/apps-ui-kit/components/table-group-menu";

export function BusySelectionBar({ busy }: { busy: boolean }) {
  return (
    <TableGroupMenu
      isChecked={false}
      isIndeterminate
      onChange={() => {}}
      withoutInfoPanelToggler
      isBlocked={busy}
      headerMenu={[
        {
          id: "move",
          label: "Move",
          title: "Move",
          iconUrl: "",
          disabled: false,
          onClick: () => {},
        },
      ]}
    />
  );
}
```

### Closing

`isCloseable` draws a cross before the info-panel button; it comes with `onCloseClick`, which
the types require together.

```tsx
import { TableGroupMenu } from "@onlyoffice/apps-ui-kit/components/table-group-menu";

export function CloseableSelectionBar({ onClose }: { onClose: () => void }) {
  return (
    <TableGroupMenu
      isChecked
      isIndeterminate={false}
      onChange={() => {}}
      withoutInfoPanelToggler={false}
      isCloseable
      onCloseClick={onClose}
      headerMenu={[]}
    />
  );
}
```

## Behaviour the types don't state

- **A `headerMenu` entry whose `disabled` is true renders nothing**, rather than a greyed
  button, so an action that does not apply to the selection disappears from the toolbar.
  `isBlocked` is the greyed state: every button and its icon, clicks ignored.
- The buttons are laid out after a separator in a scroller that runs sideways when they do not
  fit. Each button draws the icon fetched from `iconUrl` before its label, with `title` as the
  hover tooltip, or the label when `title` is empty. On a tablet the icon sits above the label;
  on a phone the label is not drawn.
- An entry with `withDropDown` calls its `onClick` and then opens its `options` in a menu under
  the button. The menu is 354px wide when its options carry descriptions; with
  `fixedDropdownStyles` it is 161px wide and five rows high at most.
- The info-panel button sits on a round background while `isInfoPanelVisible`, and its icon is
  mirrored in a right-to-left interface; the `isCloseable` cross comes before it.
- `headerLabel` replaces the select-all checkbox and the combo box with a text.

## CSS variables

| Variable                             | Default | Effect                                                                                                          |
| ------------------------------------ | ------- | --------------------------------------------------------------------------------------------------------------- |
| `--table-group-menu-checkbox-margin` | `28px`  | `margin-inline-start` of the select-all checkbox or `headerLabel`, on desktop only; below it the margin is 24px |

The `checkboxMargin` prop writes the same variable onto the toolbar itself, so when it is set it
wins over a value set on a wrapper.

## Accessibility

- The action buttons are native `<button>`s rendered by [`Button`](../button/README.md):
  reachable with Tab and activated with Enter and Space. Each one's accessible name is its label,
  even on a phone where the label is not drawn, and `isBlocked` sets the native `disabled`, which
  takes them out of the tab order.
- The select-all checkbox is a real checkbox titled "Select all" from the kit's translations;
  the toolbar itself sets no role of its own.
