# FolderTile

Tile for a folder, as a single name row or, with one flag, a tall card with a picture on top. The
single row is the usual folder in a tile listing; `isBigFolder` switches to the tall card.

## Use this when / not when

- Use for a folder in a tile listing.
- Not for a document — [`FileTile`](../file-tile/README.md) has the thumbnail chain and the
  badge strip.
- Not for a room or a template — [`RoomTile`](../room-tile/README.md) and
  [`TemplateTile`](../template-tile/README.md).
- Not for a card of your own — [`BaseTile`](../base-tile/README.md) is the shell without the
  folder-specific click handling.
- **A plain click selects the folder; it does not open it.** Open it from the name, given the
  class `item-file-name` so the click does not select.

## Import

```ts
import FolderTile from "@onlyoffice/apps-ui-kit/components/tiles/folder-tile";
```

The named export `FolderTile` comes from the same subpath. It is also exported from
`@onlyoffice/apps-ui-kit/components/tiles` and from the root barrel `@onlyoffice/apps-ui-kit`.

`ThemeProvider` switches the tile to its dark colours; without it the tile stays light.
`TranslationProvider` supplies the three-dot button's tooltip, "Show File Actions". Without it the
tooltip is empty and the button is named "More options".

## Minimal example

```tsx
import { Link } from "@onlyoffice/apps-ui-kit/components/link";
import FolderTile from "@onlyoffice/apps-ui-kit/components/tiles/folder-tile";
import { TileContent } from "@onlyoffice/apps-ui-kit/components/tiles/tile-content";

const folder = {
  id: "f1",
  title: "Contracts",
  isFolder: true,
  contextOptions: [],
};

export function SimpleFolderTile() {
  return (
    <FolderTile item={folder} contextOptions={[]}>
      <TileContent>
        <Link className="item-file-name">{folder.title}</Link>
      </TileContent>
    </FolderTile>
  );
}
```

## Recipes

### Show a folder as a tall card with a picture

`isBigFolder` puts a picture above the name row and moves the badges over it. Without the flag
there is no picture at all and `temporaryIcon` is not rendered.

```tsx
import { Link } from "@onlyoffice/apps-ui-kit/components/link";
import FolderTile from "@onlyoffice/apps-ui-kit/components/tiles/folder-tile";
import { TileContent } from "@onlyoffice/apps-ui-kit/components/tiles/tile-content";

const folder = {
  id: "f1",
  title: "Contracts",
  isFolder: true,
  contextOptions: [],
};

export function BigFolderTile() {
  return (
    <FolderTile
      isBigFolder
      item={folder}
      contextOptions={[]}
      temporaryIcon="/icons/folder.svg"
    >
      <TileContent>
        <Link className="item-file-name">{folder.title}</Link>
      </TileContent>
    </FolderTile>
  );
}
```

### Select folders with a click or the checkbox

The checkbox and a plain click on the tile both report through `onSelect`. So does a tap on the
icon, in a window 600px wide or narrower. Hold `checked` yourself.

```tsx
import { useState } from "react";

import { Link } from "@onlyoffice/apps-ui-kit/components/link";
import FolderTile from "@onlyoffice/apps-ui-kit/components/tiles/folder-tile";
import { TileContent } from "@onlyoffice/apps-ui-kit/components/tiles/tile-content";

const folder = {
  id: "f1",
  title: "Contracts",
  isFolder: true,
  contextOptions: [],
};

export function SelectableFolderTile() {
  const [checked, setChecked] = useState(false);

  return (
    <FolderTile
      item={folder}
      checked={checked}
      contextOptions={[]}
      element={<span aria-hidden="true">📁</span>}
      onSelect={(next) => setChecked(next)}
    >
      <TileContent>
        <Link className="item-file-name">{folder.title}</Link>
      </TileContent>
    </FolderTile>
  );
}
```

## Behaviour the types don't state

- **The tile forwards nothing it does not name.** The menu's header comes from the first child's
  `item`.
- **`temporaryIcon` is only drawn in the tall layout.** In the short form the picture block is not
  rendered at all, so the prop is silently ignored.
- **The badges move with the layout**: over the picture when `isBigFolder` is set, after the name
  inside the content row otherwise.
- **A plain click selects, with exceptions by class name.** A click inside `.badges`,
  `.item-file-name`, `.expandButton` or `.p-contextmenu` does not select. Unlike on the file tile,
  `.tag` and `.not-selectable` are **not** exceptions here.
- **`setSelection([])` runs first**, clearing the rest of the selection, unless the click landed on
  an `img`, an `input` or an SVG shape.
- **A double click selects once**: the handler requires `e.detail === 1`.
- **Ctrl or Cmd and Shift are diverted** to `withCtrlSelect` and `withShiftSelect` and never
  select on their own; without those props such a click does nothing.
- **The three-dot button needs a `contextOptions` key on `item` as well as the prop**, the same
  gate as [`BaseTile`](../base-tile/README.md). Without the key the tile renders an empty
  `div.expandButton`.
- **Both menus need `getContextModel`.** The menu lists its entries; `contextOptions` only decides
  whether the button is drawn. Without it the button opens nothing, and a right-click swallows the
  browser's menu.
- **The menu opens on the reading side.** Its horizontal direction is taken from the interface
  direction context: right in a left-to-right layout, left in a right-to-left one.
- **Only the first child is rendered**; the rest of `children` is dropped.
- **The picture is wrapped in a link with no `href`**, so it is an `<a>` that is not focusable.
- **The checkbox replaces the icon when the pointer is over the icon**, not over the whole tile.
  It stays while `checked`. Under `isDragging`, hovering the icon changes nothing.

## CSS variables

Set them on an ancestor, such as the `TileContainer` or a wrapper of your own: the props have no
`className` or `style`. The tile declares only private fallbacks, so an inherited value reaches it.

| Variable                       | Default                          | Effect                                                                                                    |
| ------------------------------ | -------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `--tile-bg`                    | the theme's tile background      | Background of the tall card, and of the box behind the icon on hover and when `checked`                   |
| `--tile-hover-bg`              | the checked background           | Background of the tile on hover (not under `isDragging` or `isEdit`), when `checked` and under `isActive` |
| `--tile-border-style`          | the theme's border               | Border of the tile, shared with the other tiles                                                           |
| `--folder-tile-border-style`   | `--tile-border-style`            | Border of a folder tile only; wins over `--tile-border-style`                                             |
| `--tile-radius`                | `12px`                           | Corner radius                                                                                             |
| `--tile-hover-text-decoration` | the page link's hover decoration | Decoration of the name on hover and under `isActive`                                                      |
| `--tile-hotkey-color`          | the theme's hotkey colour        | Border colour under `showHotkeyBorder`                                                                    |
| `--tile-text-size`             | `14px`                           | Font size of the name                                                                                     |
| `--tile-text-weight`           | `normal`                         | Font weight of the name                                                                                   |
| `--tile-text-color`            | inherited                        | Colour of the name                                                                                        |
| `--tile-text-line-height`      | `16px`                           | Line height of the name                                                                                   |
| `--tile-badge-bg`              | the theme's badge background     | Background of each badge over the picture                                                                 |
| `--tile-badge-radius`          | `4px`                            | Corner radius of each badge over the picture                                                              |
| `--tile-badge-box-shadow`      | the theme's badge shadow         | Shadow of each badge over the picture                                                                     |
| `--tile-icon-color`            | the theme's icon colour          | Fill of a `.is-pinned` badge inside the content's `.badges`; the three-dot button does not read it        |

The single row has no background of its own until it is hovered or `checked`. The three badge
variables apply only in the tall card. In the single row the badges sit in the
name row, outside the element that reads them. `--folder-tile-border-style` and the file tile's
`--file-tile-border-style` let the two kinds of tile differ. `--tile-border-style` stays the
fallback for both.

## Accessibility

- The tile is a plain `<div>` with click and context-menu handlers: no role, no `tabindex`, no key
  handling. The keyboard reaches the three-dot button and whatever you put in the content.
- **An unselected tile cannot be selected from the keyboard.** The checkbox is `display: none`
  until the pointer is on the icon, so Tab reaches it only while `checked`.
- The checkbox carries no label; the folder's name is a sibling of it. Mark the tiles up as a list
  of your own if the count and the names matter.
- The three-dot button is named by its tooltip, "Show File Actions". Without a translation
  provider the tooltip is empty and the button is named "More options".
- Ctrl-click and Shift-click have no keyboard equivalent.
- `inProgress` sets `aria-busy="true"` on the tile, over a passed value. Its loader is decorative, so
  the tile announces the busy state once.
- The right-click menu is pointer-only. The three-dot button is the keyboard path to the same
  actions, so keep it available.
- Make the name a real link. The tile's own click selects rather than opens, and the keyboard
  cannot reach it.
- **A passed `aria-*` lands on the tile and is kept.** A passed `aria-label` or `aria-labelledby` makes it a `role="group"`, so the name is read.
