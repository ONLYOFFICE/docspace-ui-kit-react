# FileTile

Tile for a document: a thumbnail with badges over it, and a name row with a checkbox and a menu.
It is the card form of one file in the ONLYOFFICE Apps listing, and the only tile in the family with a
preview image.

## Use this when / not when

- Use for a document in a tile listing, with a thumbnail when you have one and an icon when you
  do not.
- Not for a folder — [`FolderTile`](../folder-tile/README.md) has its own two layouts and no
  thumbnail fallback chain.
- Not for a room or a template — [`RoomTile`](../room-tile/README.md) and
  [`TemplateTile`](../template-tile/README.md).
- Not for a card of your own — [`BaseTile`](../base-tile/README.md) is the shell without the
  file-specific click handling.
- **A plain click selects the file; it does not open it.** Open it from a link in the content or
  from `thumbnailClick`, as the recipes show.

## Import

```ts
import { FileTile } from "@onlyoffice/apps-ui-kit/components/tiles/file-tile";
```

Also exported from `@onlyoffice/apps-ui-kit/components/tiles` and from the root barrel
`@onlyoffice/apps-ui-kit`.

`ThemeProvider` switches the tile to its dark colours; without it the tile stays light.
`TranslationProvider` supplies the three-dot button's tooltip, "Show File Actions". Without it the
tooltip is empty and the button is named "More options".

## Minimal example

```tsx
import { Link } from "@onlyoffice/apps-ui-kit/components/link";
import { FileTile } from "@onlyoffice/apps-ui-kit/components/tiles/file-tile";
import { TileContent } from "@onlyoffice/apps-ui-kit/components/tiles/tile-content";

const file = {
  id: "d1",
  title: "Report.docx",
  fileExst: ".docx",
  contextOptions: [],
};

export function DocumentTile() {
  return (
    <FileTile item={file} contextOptions={[]} temporaryIcon="/icons/docx.svg">
      <TileContent>
        <Link className="item-file-name">{file.title}</Link>
      </TileContent>
    </FileTile>
  );
}
```

## Recipes

### Select files with a click, Ctrl and Shift

A plain click calls `onSelect` with the opposite of `checked`. A Ctrl-, Cmd- or Shift-click goes to
its own callback and never selects. Without those callbacks such a click does nothing.

```tsx
import { useState } from "react";

import { Link } from "@onlyoffice/apps-ui-kit/components/link";
import { FileTile } from "@onlyoffice/apps-ui-kit/components/tiles/file-tile";
import { TileContent } from "@onlyoffice/apps-ui-kit/components/tiles/tile-content";

const file = { id: "d1", title: "Report.docx", contextOptions: [] };

export function SelectableFileTile() {
  const [checked, setChecked] = useState(false);

  return (
    <FileTile
      item={file}
      checked={checked}
      contextOptions={[]}
      element={<span aria-hidden="true">📄</span>}
      onSelect={(next) => setChecked(next)}
      withCtrlSelect={() => setChecked((c) => !c)}
      withShiftSelect={() => setChecked(true)}
    >
      <TileContent>
        <Link className="item-file-name">{file.title}</Link>
      </TileContent>
    </FileTile>
  );
}
```

### Open the file from its name

A click on the name must not select the tile. The tile skips the selection when the click lands
inside one of these classes: `item-file-name`, `badges`, `tag`, `not-selectable`, `expandButton`.
Put one on anything that should do something else.

```tsx
import { Link } from "@onlyoffice/apps-ui-kit/components/link";
import { FileTile } from "@onlyoffice/apps-ui-kit/components/tiles/file-tile";
import { TileContent } from "@onlyoffice/apps-ui-kit/components/tiles/tile-content";

const file = { id: "d1", title: "Report.docx", contextOptions: [] };

export function OpenableFileTile({ open }: { open: () => void }) {
  return (
    <FileTile
      item={file}
      contextOptions={[]}
      thumbnail="/thumbs/report.png"
      thumbnailClick={open}
    >
      <TileContent>
        <Link className="item-file-name" onClick={open}>
          {file.title}
        </Link>
      </TileContent>
    </FileTile>
  );
}
```

### Put badges and quick actions over the thumbnail

`badges` sits in the thumbnail's top end corner and `contentElement` in its top start corner. Give
the badges the class `badges` so that clicking one does not select the tile.

```tsx
import { Link } from "@onlyoffice/apps-ui-kit/components/link";
import { Badge } from "@onlyoffice/apps-ui-kit/components/badge";
import { FileTile } from "@onlyoffice/apps-ui-kit/components/tiles/file-tile";
import { TileContent } from "@onlyoffice/apps-ui-kit/components/tiles/tile-content";

const file = { id: "d1", title: "Report.docx", contextOptions: [] };

export function BadgedFileTile() {
  return (
    <FileTile
      item={file}
      contextOptions={[]}
      thumbnail="/thumbs/report.png"
      badges={
        <div className="badges">
          <Badge label="New" />
        </div>
      }
    >
      <TileContent>
        <Link className="item-file-name">{file.title}</Link>
      </TileContent>
    </FileTile>
  );
}
```

## Behaviour the types don't state

- **The picture follows a fixed chain.** The `thumbnail` is drawn until it fails to load. Then
  comes `item.fileTileIcon` when `item.isPlugin` is set, and `temporaryIcon` otherwise.
- **A plugin icon does not win over a thumbnail**, only over `temporaryIcon`. A failed thumbnail
  stays failed while the tile is mounted.
- **A plain click selects, with exceptions by class name.** A click inside `.badges`,
  `.item-file-name`, `.tag`, `.not-selectable`, `.expandButton` or `.p-contextmenu` does not select.
  Those class names are the contract between the tile and your content.
- **`setSelection([])` runs first**, clearing the rest of the selection, unless the click landed on
  an `img`, an `input` or an SVG shape.
- **A double click selects once.** The handler requires `e.detail === 1`, so the second click of a
  pair is ignored rather than toggling back.
- **Only the first child is rendered.** Everything after it in `children` is dropped without a
  word.
- **The three-dot button needs a `contextOptions` key on `item` as well as the prop**, the same
  gate as [`BaseTile`](../base-tile/README.md).
- **Both menus need `getContextModel`.** The menu lists its entries; `contextOptions` only decides
  whether the button is drawn. Without it the button opens nothing.
- **The picture is wrapped in a link with no `href`**, so it is an `<a>` that is neither focusable
  nor announced as a link.
- **A tap on the icon selects only in a window 600px wide or narrower.**
- **`isBlockingOperation` is `pointer-events: none` and nothing else.** The keyboard still reaches
  the three-dot button, so guard its handler while an operation runs.
- **The checkbox replaces the icon when the pointer is over the icon**, not over the whole tile.
  It stays while `checked`. Under `isDragging` or `inProgress`, hovering the icon changes nothing.

## Accessibility

- The tile is a plain `<div>` with click and context-menu handlers: no role, no `tabindex`, no key
  handling. The keyboard reaches the three-dot button and whatever you put in the content.
- **An unselected tile cannot be selected from the keyboard.** The checkbox is `display: none`
  until the pointer is on the icon, so Tab reaches it only while `checked`.
- The three-dot button is named by its tooltip, "Show File Actions". Without a translation
  provider the tooltip is empty and the button is named "More options".
- **The thumbnail is decorative**, with an empty `alt`: the file's name beside it already names the
  tile.
- Ctrl-click and Shift-click have no keyboard equivalent, so range and additive selection are
  pointer-only.
- `inProgress` sets `aria-busy="true"` on the tile, over a passed value. Its loader is decorative, so
  the tile announces the busy state once.
- The badges and quick actions are your own elements. Label them, or they are not announced as
  belonging to the file.
- Make the name a real link, so the file can be opened from the keyboard. The tile's own click
  selects rather than opens.
- **A passed `aria-*` lands on the outer `<div>` and is kept**, like every prop the tile does not
  name. A passed `aria-label` or `aria-labelledby` makes it a `role="group"`, so the name is read.
