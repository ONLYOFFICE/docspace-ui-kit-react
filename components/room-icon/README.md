# RoomIcon

Square room tile that shows the room's logo, or its initials on a colour when there is none. It
sits at the start of a room row and at the top of a room tile. It draws a logo image, an inlined
cover glyph or two initials, with an optional corner badge and a pencil that opens the logo menu.

## Use this when / not when

- Use wherever a specific room is shown by name — a row, a tile, a breadcrumb, a dialog header.
- Not for the icon that says what **kind** of room it is — that is
  [`RoomLogo`](../room-logo/README.md), a fixed glyph per room type.
- Not for a person — use [`Avatar`](../avatar/README.md), which has the role ring, the status
  dot and the person-shaped placeholder.
- Not for a count or a marker on its own — that is [`Badge`](../badge/README.md). The badge
  here is a decoration on the tile, not a counter.

**It is a square with no built-in spacing and no label.** The room's name is drawn only as two
initials, and only when there is no logo; the readable name next to the tile is yours.

## Import

```ts
import { RoomIcon } from "@onlyoffice/apps-ui-kit/components/room-icon";
```

Also exported from the root barrel `@onlyoffice/apps-ui-kit`.

Needs `ThemeProvider` above it in the tree. It reads the theme in JavaScript as well as in CSS:
the colour of the initials is computed from `isBase`. Without a provider the context falls back
to the light theme. The tile then keeps light-theme initials on a dark page, and no stylesheet
override corrects that.

## Minimal example

```tsx
import { RoomIcon } from "@onlyoffice/apps-ui-kit/components/room-icon";

export function RoomRow({ name }: { name: string }) {
  return (
    <div style={{ display: "flex", alignItems: "center", gap: 12 }}>
      <RoomIcon title={name} color="4781D1" showDefault />
      <span>{name}</span>
    </div>
  );
}
```

## Recipes

### A room with a logo, falling back to initials

The logo is prefetched into an `Image` on mount, and a load failure switches the tile to the
initials on its own. You do not need to test the URL first.

```tsx
import { RoomIcon } from "@onlyoffice/apps-ui-kit/components/room-icon";

export function RoomAvatar({
  name,
  logoUrl,
}: {
  name: string;
  logoUrl?: string;
}) {
  return <RoomIcon title={name} color="4781D1" logo={logoUrl} size="48px" />;
}
```

### The editable tile

`withEditing` adds the pencil and the menu; `model` fills that menu; `onChangeFile` is what
renders the hidden file input. The entry keyed `ROOM_ACTION_KEYS.CREATE_EDIT_ROOM_UPLOAD`
(`"create_edit_room_upload"`, in the root barrel) is handed that input's ref. Every other entry's
`onClick` is called with no argument.

```tsx
import { RoomIcon } from "@onlyoffice/apps-ui-kit/components/room-icon";
import type { TModel } from "@onlyoffice/apps-ui-kit/components/room-icon";

export function LogoPicker({
  name,
  onUpload,
  onRemove,
}: {
  name: string;
  onUpload: (ref?: React.RefObject<HTMLInputElement | null>) => void;
  onRemove: () => void;
}) {
  const model: TModel[] = [
    {
      key: "create_edit_room_upload",
      label: "Upload",
      icon: "",
      onClick: onUpload,
    },
    { key: "remove", label: "Remove", icon: "", onClick: onRemove },
  ];

  return (
    <RoomIcon
      title={name}
      color="F97A0B"
      size="96px"
      withEditing
      model={model}
      onChangeFile={(e) => console.log(e.target.files)}
    />
  );
}
```

### A tile with a corner badge

The badge renders when `badgeUrl` or `badgeIconNode` is set and `withEditing` is not — the two
share the corner and editing wins.

```tsx
import { RoomIcon } from "@onlyoffice/apps-ui-kit/components/room-icon";

export function PublicRoomIcon({ name }: { name: string }) {
  return (
    <RoomIcon
      title={name}
      color="2DB482"
      size="48px"
      showDefault
      badgeIconNode={
        <svg viewBox="0 0 12 12" aria-hidden="true">
          <circle cx="6" cy="6" r="5" />
        </svg>
      }
      onBadgeClick={() => console.log("badge")}
    />
  );
}
```

## Behaviour the types don't state

- **`color` is six hex digits with no `#`.** The component prepends it. Passing `#4781D1` yields
  `##4781D1` and no background at all.
- **`size` must be a px string.** It is turned into a number after stripping `"px"`, to scale the
  cover glyph. `size="3rem"` gives a `NaN` scale and the glyph disappears; the width and height
  still apply.
- **A click anywhere on the tile toggles the logo menu**, not just on the pencil. It does so only
  when `model` has entries and the tile draws a pencil, a plus or a hover image, none archived.
  Otherwise a click does nothing.
- **Inside a clickable row, every row click toggles the menu too.** The badge's click bubbles to
  the tile as well. Picking an entry closes the menu without the click reaching the tile again.
- **The initials are the first letter of the first word and of the last**, uppercased. Before
  that, `-_[]{}()*+!?.,&\^$|#@%` are stripped and runs of whitespace collapsed. A one-word name
  gives one letter, and a name of punctuation gives none.
- **A logo object without its own `color` that fails to load draws black initials** in the light
  theme, whatever the `color` prop says. The outer element then carries `data-is-wrong-image`. A
  string `logo`, or an object with a `color`, falls back to the ordinary initials.
- **The badge is painted outside the square.** It is absolutely positioned and offset 24px from
  the centre, or 80px at `size="96px"`. A container with `overflow: hidden` clips it.
- **The file input's id is generated per instance** with React's `useId`, so
  `document.getElementById("customFileInput")` does not find it. Reach it through the ref the
  upload entry is handed, or by its `data-testid`.
- **`logo` with a `cover`** becomes a `data:image/svg+xml;base64` URL rendered through `react-svg`,
  and its `path` fill is recoloured. A plain string, or an object with only `medium`, is an
  ordinary image and is not recoloured.
- **`isTemplate`, `isEmptyIcon` and `showDefault` are checked in that order.** Each replaces
  everything below it, so a tile that is both a template and empty renders the template.
- **`isEmptyIcon` with `withEditing` draws the plus alone.** The plus already opens the menu
  from the pencil's corner, so the pencil waits for a logo.
- **In the light theme the initials are black or white.** They are black on a `color` brighter
  than 202 (of 255), and white on anything darker.
- **In the dark theme the initials take `color` itself**, on the same colour at 0.1 opacity. An
  inlined cover glyph is painted the same way. An archived tile keeps the black-or-white rule.
- **`hoverSrc` animates the tile.** On hover the initials or the cover glyph slide up and fade
  out. The background darkens to 80% brightness and the hover image fades in over it.
- **`isArchive` removes the pencil.** An archived tile with `withEditing` keeps the 64px minimum
  width and the pointer cursor, but draws neither the pencil nor its menu.
- **No `logo` means the initials**, on `color`. `showDefault` forces them while a logo exists; it
  is not needed to get them.
- **The plus button's circle takes `--accent-main`.** Without it the circle takes the theme
  provider's accent, then the kit's blue.

## CSS variables

All are read with a fallback. The component takes no `style`, so set them on an ancestor or on a
rule for your `className`.

| Variable                        | Default                       | Effect                                            |
| ------------------------------- | ----------------------------- | ------------------------------------------------- |
| `--room-icon-bg`                | white, black in dark          | Fill of the badge glyph and of the plus button    |
| `--room-icon-bg-opacity`        | `1`, `0.1` in dark            | Opacity of the coloured background                |
| `--room-icon-button-icon-color` | grey                          | Fill of the empty-state camera and template glyph |
| `--room-icon-edit-bg`           | light grey, dark grey in dark | Background of the pencil button                   |
| `--room-icon-dashed-border`     | `2px dashed` grey             | Border of the empty state                         |
| `--room-icon-empty-radius`      | `10px`                        | Corner radius of the empty state                  |

`--room-icon-bg` fills the badge glyph only when `badgeIconColor` is unset; a badge that keeps
its own colours ignores it. `--room-icon-button-icon-color` paints the template outline only
when the tile has no `color`.

The tile's own size, radius and colour are written as inline custom properties from the props.
A stylesheet cannot override them.

## Accessibility

- The outer element is a `<div>` with no role and no ARIA of its own, and it carries a click handler. The
  keyboard cannot reach it; put the room's name in a real link or button next to it.
- The initials are rendered as text, so a screen reader reads out "TR" rather than the room name.
  Treat the tile as decorative and label the row.
- A logo image is named by `title`, like the initials it replaces. The hover image has an empty
  `alt`.
- The pencil and the plus are focusable buttons, and Enter or Space opens the menu. Both are
  named by the translated "Edit".
- The badge is a focusable button only with `onBadgeClick`, named by `badgeLabel`. Without it the
  button is unnamed. The menu is a `DropDown` that closes on an outside click.
- **A passed `aria-*` lands on the outer `<div>`.** A passed `aria-label` or `aria-labelledby` makes it a `role="group"`, so the name is read. `aria-hidden` works: use it on a tile without editing buttons, beside the room's name.
